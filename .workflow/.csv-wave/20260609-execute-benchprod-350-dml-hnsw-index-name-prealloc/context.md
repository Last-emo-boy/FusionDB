# BENCHPROD-350 DML HNSW Index Name Preallocation

## Objective

Preallocate DML HNSW index names without changing the generated bytes.

## Scope

- `src/execution/dml/mod.rs`
- `src/execution/dml/insert.rs`
- `src/execution/dml/update.rs`
- `src/execution/dml/delete.rs`

## Change

- Added shared `Executor::hnsw_index_name_for_column(table_name, column_name)`.
- Replaced DML-side `format!("hnsw_{}_{}", table_name, column_name)` call sites in insert, upsert-update, update, and delete paths.
- Added a focused helper test for the generated name.

Generated names remain `hnsw_<table>_<column>`.
