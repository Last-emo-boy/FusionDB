# BENCHPROD-388 Composite Index Part Joins With Preallocation

## Objective

Avoid generic `join` calls while building composite index component keys and encoded column lists.

## Scope

- `src/execution/composite_index.rs`

## Change

- Added `join_composite_index_parts`.
- Replaced `parts.join(Self::composite_index_component_separator())` in composite index value-key paths.
- Replaced `components.join(Self::composite_index_component_separator())` in scan-prefix construction.
- Replaced `columns.join(",")` in `CompositeIndexMeta::encoded_columns`.
- Added focused helper tests for `|` component joins and comma encoded columns.

Generated bytes are unchanged: component keys still use `|`, and encoded column lists still use `,`.
