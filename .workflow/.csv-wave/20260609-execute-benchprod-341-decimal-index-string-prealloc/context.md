# BENCHPROD-341 Decimal Index String Preallocation

## Objective

Preallocate decimal index value encoding strings while keeping generated bytes unchanged.

## Scope

- `src/execution/expr/value.rs`

## Change

- Added `decimal_index_string_for_value(decimal: &str) -> String`.
- Replaced `Value::Decimal(d) => Some(format!("dec:{}", d))` with the helper.
- Added a focused unit test for the helper.

The generated encoding remains `dec:<decimal>`. This path is used by index value encoding and query/DML paths that call `Executor::value_to_index_string`; it is not a storage metadata key.
